# M3 外观切换原型说明（v0.3.0）

## 这个版本做了什么

1. 插件启动时自动读取 `BepInEx/plugins/KnightInCradle/assets/hk/` 下的
   `knight_atlas.png` + `knight_manifest.json`，生成小骑士精灵和动画播放器。
2. 按 **T** 切换：
   - 小骑士模式：把诺艾尔的渲染透明度设为 0（隐藏），在她身上挂一个小骑士
     精灵对象（挂在动画器的 Trs 上，位置跟角色一致），按她的状态播放小骑士动画
     （Idle / Run / Airborne / Slash / Dash），朝向跟随诺艾尔。
   - 诺艾尔模式：恢复显示，隐藏小骑士。
3. 移动、跳跃、攻击、受击、对话等逻辑完全没动，仍然走诺艾尔原系统。

## v0.3.0 重大改动：改用游戏自己的渲染管线

之前用 Unity 的 SpriteRenderer 显示小骑士，但 AliceInCradle 的角色不是用
普通相机渲染的——它用专用的 Mover 渲染管线（自绘 GL 网格）。标准精灵
渲染器根本不在任何可见相机的范围里，所以小骑士一直显示不出来。

v0.3.0 把小骑士**注册进游戏自己的渲染票系统**（和诺艾尔同一个绘制通道，
复用诺艾尔动画器的定位矩阵），并在小骑士模式下：

- 隐藏诺艾尔本体 + 脚下阴影 + HP/MP HUD（UIStatus）
- 彻底移除伤害/攻击（含 EP 抓取伤害、MP 扣减、攻击/施法/扔炸弹状态）
- 强制隐身（Update、LateUpdate、渲染前三层保险），虫墙、硬控、气体动画
  都不会让诺艾尔显形

## v0.2.1 修复内容

1. **小骑士依然不显示的真正原因**：游戏用“专用 Mover 相机”渲染角色，只认
   `MoverRender` 图层；小骑士之前挂在默认图层，被所有相机剔除。现在把小骑士
   对象放进 `MoverRender` 层。
2. **切回诺艾尔后隐身**：切回时连续 90 帧强制恢复诺艾尔的颜色/透明度。
3. **抓取/闪避时短暂显形**：在 Update、LateUpdate、渲染前三个阶段强制隐身，
   游戏内部动画再刷也不怕。
4. **抓取技能造成伤害**：抓取走的是 EP 系统（`EpManager.applyEpDamage`），
   已单独拦截；同时修复了“攻击拦截补丁因重载冲突挂载失败”的问题，
   攻击状态拦截现在真正生效。

## v0.2.0 修复内容

1. **小骑士不显示**：之前挂在诺艾尔 GameObject 上，但该对象的 Transform 不跟随
   角色绘制位置；现在挂到动画器 Trs（每帧跟随角色的渲染对象）上，并把精灵
   像素单位从 28 改成游戏网格的 64。
2. **脚下阴影残留**：阴影是独立的特效对象，小骑士模式下每帧销毁它；
   切回诺艾尔时重新生成。
3. **伤害保护（战斗守卫）**：小骑士模式下，诺艾尔：
   - 不受到任何 HP/MP 伤害（怪物攻击、陷阱、中毒等全部拦截）；
   - 无法进入攻击/施法/爆弹等造成伤害的状态（不会造成伤害）。
   切回诺艾尔后一切恢复正常。

## 预计看到的效果

| 诺艾尔的状态 | 小骑士播放的动画 |
|---|---|
| 站着不动 | Idle |
| 左右移动 | Run |
| 空中 | Airborne |
| 攻击（平砍/冲刺砍/空中砍） | Slash |
| 闪避 | Dash |

## 测试步骤

1. 启动游戏，进入能操作诺艾尔的画面。
2. 按 **T**：诺艾尔、阴影、HP/MP 血条应全部消失，原地出现小骑士（待机动画）。
3. 左右走动 → 小骑士应该播放跑步动画；跳跃 → 空中动画；攻击 → 挥砍动画。
4. 攻击（鼠标左键/Z/X）时确认：小骑士模式下不会打出攻击、怪物也不会打掉诺艾尔的血。
5. 故意被怪抓住/被弹幕打中：诺艾尔应保持隐身，不受伤。
6. 闪避（Shift）：诺艾尔不应闪现。
7. 再按 **T**：切回诺艾尔，一切恢复正常（人物、阴影、血条都应回来）。
8. 把 `BepInEx/LogOutput.log` 发给我，并描述看到的现象（小骑士位置偏上/偏下、
   大小是否正确、左右朝向对不对、血条有没有隐藏等）。

## 已知的可能问题（测试后反馈）

- 小骑士位置偏上/偏下：竖直偏移参数要调（v0.2.0 先按中心对齐）。
- 小骑士大小不对：像素单位参数要调。
- 小骑士被地面/物体遮挡：DRAW_ORDER 要调（v0.3.0 用的 PR1，跟玩家同一层）。
- 部分精灵方向旋转了 90°：tk2d 图集里有旋转存放的精灵，改提取工具一行即可。
- 动画太快/太慢：fps 参数来自原版数据，理论上是对的。
