# M2 空洞骑士素材提取记录

## 结论先行

空洞骑士（Unity 2020.2.2f1）的角色动画**不是** Unity 的 AnimationClip，而是 **2D Toolkit (tk2d)** 精灵动画：

- 动画数据存在 `tk2dSpriteAnimation`（ScriptableObject）里：剪辑（clip）→ 帧（帧 = 精灵 ID）
- 精灵图集存在 `tk2dSpriteCollectionData` 里：每个精灵有名字 + UV 矩形
- 玩家逻辑由 `HeroController` / `HeroAnimationController` 驱动

## 小骑士素材位置（已锁定）

| 内容 | 位置 |
|---|---|
| 全部玩家动画（178 个剪辑） | `resources.assets` 中 pathID **19580**（tk2dSpriteAnimation） |
| 精灵图集集合（891 个精灵定义，名称 `"Knight"`） | `resources.assets` 中 pathID **19578**（tk2dSpriteCollectionData） |
| 图集纹理（4096 × 4096） | `resources.assets` 中 pathID **347**（Texture2D） |

动画剪辑包含：Idle、Run、Walk、Jump、Fall、Land、Dash、Slash、SlashAlt、UpSlash、
DownSlash、Wall Slide、Walljump、Wall Slash、Double Jump、Focus（回血）、Fireball1/2 Cast、
Scream、Quake、Shadow Dash、NA Big Slash / Cyclone / Dash Slash（骨钉技艺）、Sprint、游泳、
坐姿、地图动作等。

## 提取产物（`KnightInCradle/assets/hk/`）

| 文件 | 说明 |
|---|---|
| `knight_atlas.png` | 小骑士完整图集（4096×4096，8 张裁剪后 PNG 未压缩） |
| `sprites/*.png` | 按 UV 从图集切出的 391 个精灵单帧 |
| `knight_manifest.json` | 清单：图集信息 + 精灵矩形 + 全部动画剪辑帧表 |
| `mb/*.json` | 679 个 tk2d 资产的原始 JSON 转储（含全游戏其他角色的动画） |
| `report1.txt` / `report2.txt` | 扫描报告（类型统计、脚本类统计、GameObject 列表） |

## 清单格式（knight_manifest.json）

```json
{
  "atlasFile": "knight_atlas.png",
  "atlasWidth": 4096,
  "atlasHeight": 4096,
  "spriteDir": "sprites",
  "sprites": {
    "idle_still_020001": { "x": 0, "y": 0, "w": 64, "h": 64, "flipped": 0 }
  },
  "clips": [
    {
      "name": "Idle",
      "fps": 12,
      "wrapMode": 0,
      "loopStart": 0,
      "frames": ["idle_still_020001", "idle_still_020002", "..."]
    }
  ]
}
```

`wrapMode`：0=循环，1=循环某段，2=播放一次，3=乒乓，4=随机帧。

## 运行时加载方案（已确定）

用**方案 B（免 Unity 编辑器）**：

1. mod 启动时读取 `knight_atlas.png` + `knight_manifest.json`（放在 `BepInEx/plugins/KnightInCradle/assets/hk/`）
2. `ImageConversion.LoadImage` 生成 Texture2D
3. 按清单 `Sprite.Create(tex, rect, pivot)` 生成每个精灵
4. 自写一个精简动画播放器：按剪辑名切换帧（fps + wrapMode），挂在小骑士显示对象上

不需要装 Unity 编辑器，不需要 AssetBundle。

## 待验证项

- 切图方向：tk2d 的 `flipped`（旋转 90°）精灵如果方向反了，把提取工具里的
  `Rotate(RotateMode.Rotate90)` 改成 `Rotate270` 重新跑一遍即可（一行改动）。
- 精灵锚点/偏移：后续接入诺艾尔骨架时按实际观感微调。
