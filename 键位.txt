# ============================================
#  KnightInCradle小骑士键位设置，请往下翻，调键位在最后
# ============================================
#  【技能键位】
#   回血/聚集：长按 [聚集/施法] 
#   暗影之魂：点按 [聚集/施法] 或 [快速施法]
#   黑暗降临：按住 [下] 的同时点按 [聚集/施法] 或 [快速施法]
#   深渊尖啸：按住 [上] 的同时点按 [聚集/施法] 或 [快速施法]
#   蓄力劈砍：长按 [攻击]，蓄力完成后松开 [攻击]
#   冲刺劈砍：长按 [攻击]，蓄力完成后点按 [冲刺]，在冲刺期间松开 [攻击]
#   旋风劈砍：长按 [攻击]，蓄力完成后按住 [上] 或 [下] ，松开 [攻击]，之后连续点按 [攻击] 可延长攻击段数
#   水晶升腾：长按 [超级冲刺]，蓄力完成后按住 [上]，松开 [超级冲刺]
#   虚空解放：按住 [上]，点按 [梦之钉]
#
# ============================================
# 【功能键位】
#   切换角色：点按 [切换角色]，可以在两角色间进行切换
#   护符：点按 [护符] 可以查看护符界面，坐在椅子上可以选择装配或卸下护符
#   挑衅：当小骑士位于战斗详情界面下时，点按 [挑衅] 可触发战斗
#   认真模式：点按 [认真模式]，隐藏左侧诺艾尔的立绘
#
# ============================================
#  【可用键位】
#   键盘空格键 = 空格/空格键
#   鼠标左键    = 鼠标左键
#   鼠标右键    = 鼠标右键
#   鼠标中键    = 鼠标中键
#   字母键      = A  B  C  ...  Z
#   数字键      = 0  1  2  ...  9
#   功能键      = F1  F2  ...  F12
#   方向键      = 上方向键  下方向键  左方向键  右方向键
#   Shift       = 左Shift  右Shift
#   Ctrl        = 左Ctrl   右Ctrl
#   Alt         = 左Alt    右Alt
#   其它        = 回车  Tab  Esc  退格  句号  逗号  斜杠
#                等号  减号  分号  引号  左括号  右括号  反斜杠  反引号  大写锁定
#   （也可以直接写英文键名：Space  Mouse0  Mouse1  LeftShift  Period  Comma  Slash ...）
#
# ============================================
# 【修改键位】
# ============================================
上：Q
下：鼠标右键
左：A
右：D
跳跃：W

攻击：鼠标左键
聚集/施法：C
快速施法：S
梦之钉：空格

冲刺：LeftShift
超级冲刺：LeftControl

切换角色：T
护符：O
挑衅：V
认真模式：Period
